**LearnTrack - Student & Course Management System**
**Author : Thoutam Soumyanth**
Project Overview

LearnTrack is a console-based Student & Course Management System developed using Core Java. 
The project demonstrates Java fundamentals, Object-Oriented Programming (OOP), Collections, Exception Handling, and a menu-driven console application.

The application allows administrators to manage students, courses, and enrollments using in-memory storage (ArrayList).
Class Diagram : ![LearnTrack_Class_diagram.png](images/LearnTrack_Class_diagram.png)

**Features
Student Management**
    Add Student
    View All Students
    Search Student by ID
    Update Student
    Deactivate Student

**Course Management**
    Add Course
    View All Courses
    Search Course by ID
    Update Course
    Deactivate Course

**Enrollment Management**
    Enroll Student into a Course
    View Enrollments for a Student
    Mark Enrollment as Completed
    Mark Enrollment as Cancelled

**How to Compile and Run**
        Clone or download the project.
        Open the project in IntelliJ IDEA.
        Ensure JDK 21 is configured.
        Run the Main.java file.
        Use the console menu to manage Students, Courses, and Enrollments.
